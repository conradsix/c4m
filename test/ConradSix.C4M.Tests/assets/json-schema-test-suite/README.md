# JSON Schema Test Suite

The draft 2020-12 cases for the keywords C4M's schema validator supports, from
https://github.com/json-schema-org/JSON-Schema-Test-Suite at commit
`8cab295687d150de3900a160c6ad002b53ddb30e` (MIT, see `LICENSE`). They are test data only.

`optional/format/uri.json` is the suite's optional uri format check: C4M asserts `uri`, the one format zod emits
without a pattern.
